## 📖 توضیحات پروژه (Persian Description)

این پروژه یک پلتفرم جامع و هوشمند برای مدیریت یکپارچه کلاس درس، پیگیری وضعیت تحصیلی دانش‌آموزان و ارائه محتوای آموزشی تعاملی است. این سیستم با هدف تسهیل ارتباط آموزشی بین معلمان و دانش‌آموزان توسعه یافته و دارای دو پنل مجزا با امکانات اختصاصی برای «معلمان» و «دانش‌آموزان» می‌باشد.

### ✨ ویژگی‌ها و امکانات برجسته

#### 👨‍🏫 ۱. پنل مدیریت همکاران (معلمان)
این پنل به معلمان ابزارهای کاملی برای مدیریت کلاس و محتوای آموزشی ارائه می‌دهد.
* **مدیریت دانش‌آموزان و دروس:** امکان افزودن دانش‌آموزان جدید و تعریف دروس مختلف.
* **ثبت عملکرد تحصیلی:** ثبت نمرات، غیبت‌ها و تولید نمودار پیشرفت تحصیلی برای هر دانش‌آموز.
* **مدیریت تکالیف:** ارسال تکالیف مشخص برای دانش‌آموزان و پیگیری آن‌ها.
* **سیستم هوشمند «خوانداری» (Text-to-Speech & Transcript):** قابلیت ترنسکریپت (هایلایت همگام) که دقیقاً همان کلمه‌ای که در حال خوانده شدن است را در متن هایلایت می‌کند.
* **طراحی آزمون و سوالات تعاملی:** معلم می‌تواند از متن درس، سوالات درک مطلب طراحی کند. این سوالات به گونه‌ای تنظیم می‌شوند که هنگام پخش درس توسط دانش‌آموز، روی صفحه ظاهر شده و پاسخ‌ها برای معلم ثبت می‌شود.
* **مدیریت حساب کاربری:** نام کاربری و رمز عبور اولیه هر دانش‌آموز «کد ملی» اوست. معلم امکان تغییر رمز عبور دانش‌آموزان را نیز دارد.

#### 🎓 ۲. پنل دانش‌آموزی
این پنل محیطی شخصی‌سازی شده برای هر دانش‌آموز است تا روند یادگیری خود را دنبال کند.
* **ورود یکپارچه:** با استفاده از کد ملی.
* **داشبورد تحصیلی (کارنامه آنلاین):** مشاهده تمامی نمرات، نمودار پیشرفت، روزهای غیبت و تکالیف.
* **دسترسی به بخش خوانداری:** پخش صوتی دروس با قابلیت هایلایت همزمان متن جهت درک بهتر و تندخوانی.
* **پاسخگویی به سوالات پاپ‌آپ:** الزام دانش‌آموز به پاسخگویی به سوالات گنجانده شده در دل فایل صوتی دروس.
* **ماژول تعاملی یادگیری حروف الفبا:**
  * مشاهده انیمیشن‌های نحوه نوشتن صحیح حروف.
  * پخش تلفظ صوتی حروف و کلمات مثال.
  * یادگیری در قالب جملات کاربردی (مثل "بابا آب داد") با حروف متمایز.
  * پشتیبانی از ترنسکریپت و هایلایت در حین پخش صوتی جملات.



## 📖 About the Project


This platform is a comprehensive educational web application designed to manage student profiles, track academic progress, and monitor school activities. A standout feature of this system is its innovative Persian reading education module. By leveraging AI technologies such as Text-to-Speech (TTS) and Speech-to-Text (Transcript), administrators can generate and prepare grade-specific interactive content to enhance students' reading skills. The entire system is backed by MongoDB to ensure flexible, scalable, and efficient database management.

## ✨ Key Features
- **Role-Based Architecture:** Dedicated, separate panels for "Students" and "Teachers," each with its own unique authentication and registration flow.
- **Real-Time Progress Tracking:** Enables both educators and learners to monitor grades, activities, and academic advancements instantly.
- **Comprehensive Teacher Dashboard:** Empowers educators with full authority to manage student profiles, oversee activities, and control the learning environment.
- **AI-Powered Learning:** Integrates TTS and Transcript services for an interactive Persian reading practice experience.

## 💻 Tech Stack
Built with a focus on high performance, type safety, and modern UI/UX principles:
- **Framework:** Next.js
- **Language:** TypeScript
- **Database:** MongoDB
- **Styling:** Tailwind CSS
- **State Management:** Redux
- **Deployment:** Vercel
